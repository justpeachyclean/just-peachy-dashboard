Dashboard Tabs &amp; Features Tab 1 — Overview The main at-a-glance view. Show all critical KPIs front and center. Recurring client count (live from MaidCentral) Show daily change: +/- vs yesterday YTD revenue with monthly breakdown Bar chart: actual vs goal each month Color code: green if over goal, yellow if within 5%, red if under Attrition rate (current month) Formula: cancellations ÷ total recurring clients at start of month Show trend arrow vs last month Daily revenue vs break-even and goal Show today's revenue, break-even line, daily goal, stretch goal Alert banner for any missing data entries older than 3 days Tab 2 — Sales &amp; Leads Monthly lead funnel table: Leads In → Quoted → Closed → Close % Quote rate vs 90% goal (color coded) Close rate vs 40% minimum (color coded) Initial clean retention rate (clients kept as recurring ÷ initial cleans completed) Cancellations, skips, complaints per month Dollar value gained from new recurring (annualized per client) Dollar value lost from cancellations (annualized per client) Tab 3 — Bonus Tracker This tab is built around the Sales Bonus Agreement. All calculations must match the agreement exactly. Per Rep Display: Close rate for current month (updated live) Recurring ratio — % of closed jobs that are weekly or bi-weekly Current tier automatically calculated: Tier 1: close rate &gt;= 40% → $200 Tier 2: close rate &gt;= 40% AND recurring ratio &gt;= 50% → $400 Tier 3: close rate &gt;= 40% AND recurring ratio &gt;= 75% → $700 None: close rate &lt; 40% → $0 Quarterly consistency streak tracker (3 consecutive months at same tier) Tier 2 streak = +$250 bonus Tier 3 streak = +$500 bonus Visual streak indicator (3 dots — filled = qualifying month) Alert if rep is at risk of losing tier mid-month Payout Calendar: Show each qualifying month, the estimated bonus, and the payout month (2 months later) Status: Pending / Due This Month / Paid Flag: rep must be actively employed at payout — show warning if any termination is logged Audit log: show when data was last updated and by whom The bonus agreement requires close rate = closed sales ÷ quotes given. Use MaidCentral data verified against the bonus tracking spreadsheet. Do not use GHL data alone. Tab 4 — Unit Economics This is the new tab powered by QuickBooks + existing data. Show all three cost metrics. Customer Acquisition Cost (CAC): CAC (One-Time) = Monthly marketing spend ÷ one-time closes that month CAC (Recurring) = Monthly marketing spend ÷ recurring closes that month Show monthly trend chart Benchmark: flag if CAC recurring exceeds LTV ÷ 12 Employee Acquisition Cost: Formula: Total recruiting spend ÷ new hires started that month Recruiting spend pulled from QuickBooks (Indeed, job boards, background checks) Show monthly trend Cost of Employee Turnover: Formula per departing employee: Recruiting cost to replace (avg employee acquisition cost) Training cost = training hours (manual entry) x avg hourly labor cost (manual entry) Lost productivity = estimated revenue per tech per day x avg ramp-up days (manual entry) Total turnover cost = sum of all three components per departure Show monthly total and YTD total Log each departure with date and estimated cost Training hours, avg hourly cost, and ramp-up days are set once in Settings and applied to all turnover calculations automatically. Tab 5 — Hiring Pipeline Funnel: Interviews Scheduled → Showed Up → Offers → Started Show rate at each stage (e.g., 41% show rate) with color coding Monthly table breakdown Staff headcount: current cleaning techs, commercial techs Net headcount change per month Alert if show rate drops below 50% — suggest GHL reminder automation 5. Date (auto-filled to today, can be changed) Number of new hires started Number of staff quit or fired (with dropdown: Voluntary / Terminated) Call-ins / absences today (accepts 0.5 increments) Number of revenue-generating employees this week Marketing spend this week (if not in QuickBooks) Notes field (free text, timestamped) Settings page (owner only) for one-time configuration: Break-even daily revenue target Daily revenue goal and stretch goal Average training hours per new hire Average hourly labor cost Average ramp-up days before new hire is fully productive QuickBooks expense category names (marketing, recruiting, training) 6. Webhook API Specification The backend must expose these endpoints to receive data from Zapier: Endpoint Method Payload / Purpose POST /api/webhook/ghl POST Receives lead, quote, close, interview events from GHL POST /api/webhook/maidcentral POST Receives revenue, recurring, cancellation, skip, complaint events POST /api/webhook/quickbooks POST Receives expense data (or use nightly pull — see below) GET /api/data/summary GET Returns all KPIs for the current month — used by the frontend POST /api/entry/manual POST Receives manual data entries from the /entry form GET /api/bonus/current GET Returns bonus tier and payout data for each sales rep GET /api/economics GET Returns CAC, employee acquisition cost, turnover cost data All webhook endpoints should validate a shared secret token in the header (X-Webhook-Secret) to prevent unauthorized posts. 7. QuickBooks Integration Detail Use the QuickBooks Online API (v3) with OAuth2 authentication. Auth flow: standard OAuth2. Store refresh token securely in environment variable. Nightly cron job (2am EST): call QuickBooks Reports API → ProfitAndLoss report Filter by date range: first day of current month to yesterday Extract rows matching configured expense category names (set in Settings) Store totals in database: { month, category, amount } Frontend reads from database — never calls QuickBooks directly QuickBooks API docs: https://developer.intuit.com/app/developer/qbo/docs/api/accounting/report-entities/profitandloss 8.
